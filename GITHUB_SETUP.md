## For Contributors

### Cloning the Repository

```bash
# SSH (recommended)
git clone git@github.com:Cortexa-LLC/ai-pack.git

# HTTPS
git clone https://github.com/Cortexa-LLC/ai-pack.git
```

### Using as a Git Submodule

To add ai-pack to your project:

```bash
# Add as submodule in .ai-pack directory
git submodule add https://github.com/Cortexa-LLC/ai-pack .ai-pack

# Initialize and update submodule
git submodule update --init --recursive
```

### Updating Your Submodule

```bash
# Pull latest changes
git submodule update --remote .ai-pack

# Commit the update
git add .ai-pack
git commit -m "Update ai-pack to latest version"
```
