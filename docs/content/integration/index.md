# Integration Guides

AI-Pack integrates with various tools and platforms to enhance your development workflow.

## Available Integrations

### [Claude Code](./claude-code)
Native integration with Claude Code CLI providing commands, skills, rules, and enforcement hooks.

### [Beads](./beads)
Git-backed task tracking system for persistent, cross-session task management.

### [GitHub](./github) (Optional)
Bidirectional sync with GitHub Issues, CI/CD monitoring, and epic management.

## Setup Order

1. **Claude Code** - Core integration (required for best experience)
2. **Beads** - Task memory system (required)
3. **GitHub** - Issue tracking and CI/CD (optional)
